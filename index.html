ClipStudio

ClipStudio is a personal desktop tool that turns long gaming and livestream videos into short vertical clips (YouTube Shorts) with subtitles, and uploads them to the operator's own YouTube channels.

It runs locally on a single Windows computer and is used only by its owner. It is not offered to the public.

How it uses YouTube

  • Signs in with Google so the owner can choose which of their own YouTube channels to upload to.
  • Uploads finished clips with a title, description and tags written by the owner.
  • Reads the channel name and picture so the owner can see which channel is connected.

ClipStudio uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
