ClipStudio

ClipStudio is a personal desktop tool that turns long gaming and livestream videos into short vertical clips (YouTube Shorts and TikTok videos) with subtitles, and publishes them to the operator's own YouTube channel and TikTok account.

It runs locally on a single Windows computer and is used only by its owner. It is not offered to the public.

How it uses YouTube

  • Signs in with Google so the owner can choose which of their own YouTube channels to upload to.
  • Uploads finished clips with a title, description and tags written by the owner.
  • Reads the channel name and picture so the owner can see which channel is connected.

How it uses TikTok

  • Signs in with TikTok (Login Kit) so the owner can connect their own TikTok account.
  • Sends a finished clip to the owner's TikTok inbox as a draft (Content Posting API, video.upload). The owner adds the caption and posts it in the TikTok app.
  • Reads the account's display name and avatar so the owner can see which account is connected.

ClipStudio uses YouTube API Services and the TikTok for Developers APIs. By using it you agree to the YouTube Terms of Service and the TikTok Terms of Service.
